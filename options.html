VK Copy Post

Значок копирует HTML поста. При наведении появляется подсказка «Скопировать HTML». В мессенджере VK (/im) кнопка отключена. Настройка применяется сразу во всех вкладках.

Удаляет #хештеги, в том числе #тег@сообщество, из текста. Адреса ссылок сохраняются. По умолчанию выключено.

Обратная связь

К сообщению будут приложены последние 20 событий: время, версия, этап копирования и коды ошибок. Журнал хранится только в этом браузере: до 50 событий за последние 7 дней. Тексты постов, переписка, адреса страниц и содержимое буфера не записываются.

Посмотреть диагностику перед отправкой
Журнал загружается…

Откроется публичная форма GitHub Issues с диагностикой. Проверьте содержимое, опишите проблему и нажмите Submit new issue. Нужна учётная запись GitHub. Не добавляйте личные данные.

Обновления

Проверяем опубликованные стабильные релизы на GitHub раз в сутки, пока работает Chrome. О каждой новой версии уведомляем один раз. Текст постов и адреса страниц не отправляются.

Открыть релизы на GitHub

Как обновить: скачайте файл vk-copy-post.zip из раздела Assets нужного релиза. Распакуйте и замените файлы в прежней папке расширения. На странице chrome://extensions нажмите кнопку перезагрузки на карточке VK Copy Post, затем перезагрузите вкладки VK. Настройки сохранятся, если оставить ту же папку и не удалять расширение.
